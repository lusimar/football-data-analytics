# ⚽ Football Data Analytics

Projeto de engenharia e análise de dados utilizando dados de futebol da Premier League.

O objetivo do projeto é simular uma arquitetura moderna de dados utilizando o conceito de Medallion Architecture (Bronze, Silver e Gold), permitindo ingestão, transformação e análise de dados esportivos.

## 🚀 Tecnologias utilizadas

- Python
- Pandas
- Google Sheets
- Looker Studio

## 🧱 Arquitetura de dados

O pipeline é dividido em três camadas:

### Bronze
Armazena os dados brutos das partidas de futebol exatamente como foram ingeridos.

### Silver
Realiza limpeza e padronização dos dados, removendo inconsistências e organizando as colunas para análise.

### Gold
Cria tabelas analíticas agregadas utilizadas para dashboards e análise de performance dos times.

## 📊 Dashboard

Os dados da camada Gold são enviados para o Google Sheets e utilizados para criação de dashboards no Looker Studio.

Principais métricas analisadas:

- Total de gols por time
- Média de gols por partida
- Ranking de equipes
- Performance ofensiva dos clubes
